# Midnight Movie Club

## Overview

Midnight Movie Club is a responsive landing page for a fictional community movie club. The website promotes weekly film screenings, highlights popular genres, showcases upcoming movies, and provides information for prospective members.

This project was created as part of the Codecademy Responsive Club Website challenge and demonstrates the use of semantic HTML, Flexbox layouts, responsive design principles, and modern CSS styling.

Site: https://imabyrd.github.io/Codecademy-Project-Club-Homepage/

## Features

* Responsive navigation bar
* Hero section with cinematic imagery and call-to-action button
* About section introducing the club
* Featured genres section
* Upcoming screenings with movie cards
* Join and contact information section
* Image divider between content sections
* Mobile-friendly layouts using Flexbox and media queries

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Google Fonts
