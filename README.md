# Midnight Movie Club

A cinematic, responsive landing-page concept for a fictional movie club, built for Codecademy's **Responsive Club Website** challenge.

**[View the live site](https://imabyrd.github.io/Codecademy-Project-Club-Homepage/)**

## Overview

This project emphasizes independently chosen art direction alongside frontend fundamentals. The page introduces the club, highlights film genres and screenings, and invites visitors to learn more.

## What I built

- Multi-section HTML landing page with header, hero, about, screenings, and contact/join content.
- CSS-based responsive layouts using Flexbox and media queries.
- A dark, cinema-inspired visual system, with movie imagery, typography, and icon treatments.
- Repeated content patterns for film cards and category presentation.

## Tools

HTML5, CSS3, Flexbox, and media queries. This is a static website, not a full membership or event-booking service.

## Run locally

```bash
git clone https://github.com/Imabyrd/Codecademy-Project-Club-Homepage.git
cd Codecademy-Project-Club-Homepage
```

Open `index.html` in a browser.

## What this project demonstrates

Responsive layout construction, visual hierarchy, page composition, CSS organization, and adaptation of a course brief into an individual design.

## Limitations and next steps

The navigation contains placeholder links for some sections, and the site does not implement sign-up or booking functionality. Potential refinements include verifying keyboard navigation and image alt text, refining mobile interactions, and making screening information data-driven.
